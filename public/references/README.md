# Reference images

This app ships **no copyrighted Coneheads imagery**. All instructional diagrams are original SVGs.

## Private reference photos

Put your own reference stills or build photos in `public/references/private/`.
That folder is **git-ignored**, so nothing you put there is committed or deployed — it's only
available when you run the app locally (`npm run dev`) at `/references/private/<file>`.

The research's image manifest (see the Research page) classifies film stills as
"private reference only; do not redistribute". Keep them here, not in the repo.

## Photos taken in the app

Photos added in Makeup Station or the Build Log are stored in your browser's IndexedDB on that
device only. They're included in a JSON export only if you tick "Include photos".
